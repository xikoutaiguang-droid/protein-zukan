## サイトの仕組み（重要・2026-11-14 調査）
- ほぼ全ページを Google Apps Script（リポジトリの gas/ はそのコピー。clasp設定は .gitignore）が生成し、GitHub API で push している。
- 毎朝 5:12 JST に jobFetchAndBuild（楽天価格取得→buildAllPages）。index / articles / brands / methods / items / 記事ページ / sitemap.xml / robots.txt を上書きする。
- 記事の原稿は Google スプレッドシートの「記事」シート（記事ID・タイトル・説明・公開日・更新日・ステータス・本文）。本文は Markdown＋埋め込み（{{item:ID}} {{list:RTD}} {{pr:商品名|URL|一言}}）。
- → リポジトリで生成済みHTMLを直接直しても、次回ビルドで上書きされる。sitemap.xml も毎日作り直される（手で足したURLは消える）。
- → 新しい記事は「記事」シートに入れるのが正規ルート。Claude はシートを触れないので、原稿を _ops/drafts/ に置いて西口さんに貼ってもらう形が現実的（要相談）。
